Custom response rules

[edit]

These are custom trigger rules used by the Axe. Note that responses can have multiple rules, and only trigger if all rules are fulfilled.

  • Isaxe: Response triggers only when the hero is Axe. This rule is used by all responses listed here.
  • IsValidBerserkersCall: Response triggers when at least 1 enemy hero was caught with Berserker's Call.
  • IsInvalidBerserkersCall: Response triggers when no enemy hero were caught with Berserker's Call.
  • IsBattleHunger: Response triggers when the source ability is Battle Hunger.
  • IsCullingKill: Response triggers upon killing an enemy hero with Culling Blade.
  • IsAxeTauntComeAndGetIt: Response triggers when the source is Taunt: Come and Get It!.
  • IsAxeTauntGoodDaySir: Response rule for an unreleased taunt.
  • IsAxeTauntComeAtMeBro: Response rule for an unreleased taunt.
  • IsAxeLoadoutSpawn: Response triggers when Axe spawns within the loadout menu.
